# Missing Person Poster Maker

A single-page tool for building a square (2160 x 2160) missing person appeal poster for Facebook.

Add a photo, fill in the details, and save the image. Everything runs in the browser: photos and details are never uploaded anywhere. Text fields and the logo are remembered on the device you use.

## Publishing with GitHub Pages

1. Open the repository's **Settings**, then **Pages**.
2. Under **Build and deployment**, set **Source** to *Deploy from a branch*.
3. Choose the `main` branch and the `/ (root)` folder, then **Save**.
4. After a minute or two the site is live at `https://<username>.github.io/<repository>/`.

Only use the tool for genuine appeals, with details confirmed by the police.
